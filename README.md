# Mi Hoja de Vida - John Gonzalez

Proyecto de página web personal realizado con HTML y CSS.

## Estructura

- `index.html`: página principal.
- `style.css`: estilos de la página.
- `imagenes/`: foto de perfil.
- `datos-personales/`: carpeta para documentos/datos personales.
- `estudios/`: carpeta para información académica.
- `experiencia/`: carpeta para experiencia laboral.
- `capacitaciones/`: carpeta para cursos.
- `enlaces/`: carpeta para enlaces y documentos complementarios.
